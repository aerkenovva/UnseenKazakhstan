# Unseen Kazakhstan

Unseen Kazakhstan is a responsive multi-page travel website dedicated to hidden and lesser-known destinations across Kazakhstan.

The project was created as part of the **Web Technologies 1 (Front-End)** course.

## Project Pages

The website contains 6 HTML pages:

1. `index.html` — Home
2. `destinations.html` — Hidden Gems
3. `regions.html` — Regions & Map
4. `creators.html` — Team
5. `tips.html` — Travel Tips
6. `planner.html` — Trip Planner

Each team member is responsible for at least two HTML pages.

## Responsiveness

The website automatically adapts to different screen sizes.

- Desktop — multi-column layouts
- Tablet — reduced number of columns
- Mobile — stacked content and collapsed navigation

CSS Media Queries and Bootstrap responsive classes such as `col-sm`, `col-md`, and `col-lg` are used throughout the project.
